# What is a Hacker? CTF

A mystery wrapped in code. Can you unravel what it truly means to be a hacker?

## 🎮 Getting Started

1. **Clone the repository**  
   ```bash
   git clone (the repo-link can be found in the url)
   cd what-is-a-hacker-ctf
````

2. **Run the challenge**

   ```bash
   python3 ctf.py
   ```
3. **Follow the prompts**, press Enter when asked, and pay close attention to every hint.

## 🛠️ Requirements

* Python 3.6 or higher
* No external libraries needed

## 🤫 Hints

* Think old-school: sometimes the simplest transformations hide the biggest secrets.
* Every puzzle hides a piece of the answer—stay curious.

> “The true hacker sees possibilities where others see walls.”

Happy hacking! 🚀
